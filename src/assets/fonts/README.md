# Barlow (SIL Open Font License 1.1)

Latin subset (covers French accents and `œ`), taken unmodified from the
`@fontsource/barlow@5.3.0` and `@fontsource/barlow-semi-condensed@5.3.0` npm packages.
Only the variants actually used are shipped: Barlow 400/500/600/700, Barlow Semi Condensed 400/500/600.
Licence text: `OFL-Barlow.txt`. Loaded with `next/font/local` in `src/lib/fonts.ts`.
