# Escalia V7.1 — Brand Experience & Assist

## Language experience
`LocaleSwitcher` is the single reusable Globe + FR/EN menu for public and private headers. It uses next-intl
navigation, preserves the internal pathname and query string, and records only the temporary session override
`escalia_locale_session`. Language remains independent from currency, country, time zone and tax jurisdiction.

`AuthDraftPreserver` keeps only non-sensitive form values in `sessionStorage` during a locale navigation. Password
fields are deliberately excluded; no draft leaves the browser session.

## Authentication editorial panel
`AuthBrandPanel` is mounted only on desktop auth layouts. It uses the official light sixplex asset unchanged and renders
all management indicators as React components. The same image receives a restrained dusk treatment in dark mode because
no matched official dark sixplex asset has been supplied (`BRAND_ASSETS_PENDING`). Replace the `Image` source through
the component when an approved dark asset exists.

The 20 editorial signatures live in `messages/*/auth.json`. Their index is held in session storage so it survives
locale/theme changes and is stable while a visitor types. They are brand copy, never testimonials.

## Escalia Assist
Technical name: **Escalia Assist**. Brand rendering: **Escalîa Assist**. It is mounted once in
`src/app/[locale]/layout.tsx` and is intentionally local/presentation-only:

- no network request, BFF endpoint, provider SDK, conversation input, cookie, tracking or analytics;
- no page context, business data, PII, token or conversation content is sent or logged;
- public and private spaces receive the same generic resources;
- desktop: floating 56 px launcher + 380 px / 560 px maximum panel; mobile: safe-area-aware sheet;
- ESC, focus management and reduced-motion handling come from Radix Sheet / Tooltip.

Future integration requires an approved provider, BFF contract, server authorization and tenant isolation, validation,
limits, privacy policy and the canonical skill `.agents/skills/escalia-assist-expert/SKILL.md`.
